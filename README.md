# console_PhotoEditing_project_13_10_2026
Photo Editing Application (Console Application)

Course: CS213 - Object-Oriented Programming
Faculty: Faculty of Computers and Artificial Intelligence, Cairo University
Supervisor: Dr. Mohamed El Ramly

1. Project Description

This project is an image processing application developed using C++. The application provides a command-line console interface that allows users to load images, apply various image processing filters, and save the modified images.

2. Tools and Technologies

Programming Language: C++
Interface: Console / Command Line Interface (CLI)
Compiler:** GCC / g++ (MinGW or compatible C++ compiler)
Operating System: Windows / Linux / macOS

3. Requirements

Before running the application, make sure the following tools are installed:

1. A C++ Compiler (e.g., GCC via MinGW for Windows or build-essential for Linux).
2. Command Line / Terminal access.

4. Project Files

The project includes the following source files:

`main.cpp` - Application entry point and main menu execution loop.

5. How to Build and Run

1. Open your Terminal or Command Prompt.
2. Navigate to the project directory containing the `.cpp` files.
3. Compile a C++ file using `g++`:  

g++ CS213_A1_Part2_S23_S24_20250252_20250483_20250569_2025077.cpp -o program

4. Run the compiled application:
Windows:
cmd
program.exe

Linux / macOS:
bash
./program

6. How to Use the Application

1. Launch the application: Run the compiled binary file from your terminal.
2. Enter Image Path: When prompted, enter the file path of the image you want to process.
> NOTE: The file path MUST NOT CONTAIN ANY SPACES (e.g., use `C:/Images/photo.jpg` 
instead of `C:/My Images/photo.jpg`).

3. Select Options: Navigate through the menu by typing the corresponding [number] for the desired filter or action.
4. Apply Filters: Choose from the available image editing operations.
5. Save Image: Enter the output file path (without spaces) to save your modified image.
